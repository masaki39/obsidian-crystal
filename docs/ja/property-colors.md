# プロパティカラー

Properties エディターでプロパティ名に専用の文字色を付け、重要なものを見つけやすくします。変わるのはプロパティ名の見た目だけで、ノートは変更されません。

[← ドキュメント索引に戻る](README.md)

## 要件

- なし。

## クイックセットアップ

1. **Settings → Crystal → Property colors** を開きます。
2. **Add rule** を選択し、`status` と入力して色見本を選びます。
3. `status` プロパティを持つノートを開きます。その名前が選んだ色で表示されます。

## コマンド

この機能にコマンドはありません。設定はすべて設定画面で行います。

## 設定

**Settings → Crystal → Property colors**

| 設定 | デフォルト | 説明 |
|---|---|---|
| **Color palette** | Tokyo Night | すばやく選ぶための色見本: Tokyo Night、Catppuccin Mocha、Nord、Dracula、Gruvbox。パレットを変えても、すでに選んだ色は変わりません。色見本の横のカラーピッカーでは任意の色を指定できます。 |
| **All properties** | （テーマの色） | 個別のルールがないすべてのプロパティ名の色。リセットするとテーマの色に戻ります。 |
| **Rule *n*** | — | カンマ区切りの 1 つ以上のプロパティ名と色。名前の欄には Vault 内のプロパティ名が候補として表示され、選んだ色でプレビューされます。 |
| **Add rule** | — | 新しいルールを追加します。 |

## 使用例

| ルール | 効果 |
|---|---|
| `status` → 赤 | `status` が赤で表示されます。 |
| `status, priority` → オレンジ | どちらもオレンジで表示されます。 |
| **All properties** → グレー、`tags` → 青 | `tags` は青、それ以外のプロパティ名はすべてグレーになります。 |

## 注意とトラブルシューティング

- **名前の大文字・小文字は区別されません。** `Status` と `status` は同じルールに一致します。
- **同じ名前が複数のルールにある場合は、下にあるルールが優先されます。**
- 色が付くのはプロパティの*名前*だけです。値はテーマのスタイルのままです。
