## What's Changed

### New Features

- **サイドバーの自動開閉**: ウィンドウのリサイズに合わせて、エディターが **Minimum editor width** より狭くならないようにサイドバーを開閉する。最小幅は設定値（既定 900px）、サイドバーは実際の幅を使う。**Settings → Crystal → General** の **Auto open/close sidebars** で有効化（既定オフ）。コマンド **Sidebar: Toggle auto open/close** でも切り替えられる。**Sidebar priority** で先に開く側（左・右）を選べ、**Sidebar: Show measured widths** で使用中の値を確認できる。
