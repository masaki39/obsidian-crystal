## What's Changed

### New Features

- **ウィンドウの透明度を設定画面から調整できるように**: 設定の **General** セクションに **Window opacity** スライダーを追加（0.5〜1.0、0.05 刻み）。動かすとリロードなしで即座にウィンドウへ反映される。デスクトップ専用で、プラグインを無効化すると 1.0 に戻る。

### Changed

- **「Window: Toggle opacity」コマンドが直近の透明度を記憶するように**: スライダーで 0.7 などに設定してからコマンドを使うと `1.0 ⇔ 0.7` で切り替わる（以前は常に 0.9 に戻っていた）。
