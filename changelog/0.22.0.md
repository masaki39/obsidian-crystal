## What's Changed

### New Features

- **Auto bullet（Cosense風の自動箇条書き）を内蔵**: 行頭で半角スペース・全角スペース・Tab を打つと `- ` の箇条書きになる。既存テキスト行の行頭でも `foo` → `- foo` になる。Undo で元に戻せる（直前の入力と同じ Undo 単位にまとめられ、直前の入力ごと戻る場合がある。IME の確定経由で入った全角スペースは2回の Undo で戻る）。[Auto Bullet](https://github.com/takitsuba/obsidian-auto-bullet) プラグインをもとに、次の点を改善した。
  - フロントマター、` ``` ` / `~~~` のコードブロック、`$$` 数式ブロック（1行の `$$x$$` は除く）、見出し、引用・コールアウト、既存のリスト（`* ` `+ ` `1) ` チェックボックスを含む）、テーブル、水平線では発動しない。
  - 貼り付け・削除・Undo/Redo・IME 変換中（未確定）の入力では発動しない。
  - Tab は発動条件を満たすときだけ処理し、既存リスト上の Tab は通常どおりインデントする。
  - **Settings → Editor** で全体のオン/オフと各トリガーを切り替えられる（既定はすべてオン）。Auto Bullet プラグインと併用すると二重に処理されるので、そちらは無効化すること。
- **Editor: Move cursor after list marker コマンドを追加**: リストマーカー（`- ` `* ` `+ ` `1. ` `1) `）の後ろ、チェックボックスがあればチェックボックスの後ろへカーソルを移動する。それ以外の行では行頭へ移動する。

### Changed

- **コードの構成を整理**: `main.ts` をプラグインのライフサイクルだけに絞り、機能ごとに `src/features/<機能>/`、設定を `src/settings/`、共通処理を `src/shared/` に分けた。大きなファイル（設定タブ・Gamification・Marp・エディタ・AI・Bluesky・デイリーノート）は役割ごとに分割した。コマンド ID・設定・保存データは変わらない。
- **アンロード時の後片付けを確実にした**: 画像の貼り付け/ドロップの監視を Obsidian の登録 API に移し、Gamification の保存・演出タイマーはアンロード時に止めるようにした。
