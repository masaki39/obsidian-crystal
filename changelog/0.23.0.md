## What's Changed

### New Features

- **Marp: Create slide from current note コマンドを追加**: 現在のノートを親として Marp スライドノートを作成し、新規タブで開く。
  - ファイル名は `<プレフィックス><日付><区切り><親タイトル>`。日付は moment 書式で指定でき（空なら日付なし）、親タイトルはファイル名か `aliases[0]` を選べる。同名ファイルがあれば連番を付ける。
  - 保存先は Marp Slide Folder Path（空なら親ノートと同じフォルダ）。
  - フロントマターに `marp: true` を入れ、`theme`・`paginate`・`header` の既定値を設定できる。`header` では `{{title}}`・`{{date}}`・`{{date:FORMAT}}` が使える。本文には `# 親タイトル` を入れる。
  - 親ノートの `slide` とスライドの `parents` に相互リンクを追加する（プロパティ名は設定可、空なら追加しない）。
  - 設定は **Settings → Marp → New slide from note**。
