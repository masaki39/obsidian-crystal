## What's Changed

### New Features

- **ステータスバーの項目を並べ替え・非表示にできる機能を追加**: 設定の **Status bar** セクションで、Obsidian のステータスバーに並ぶ項目（他のプラグインやコア機能のものを含む）をドラッグ&ドロップ（または ↑↓ ボタン）で並べ替えられる。各項目の目のアイコンで表示/非表示も切り替え可能。並び順は `.status-bar` の flexbox に `order` を、非表示はクラスを付与して実現しており、DOM は破壊せず、機能を無効化するとネイティブの状態に戻る。プラグインが項目を遅延生成した場合や実行中にトグルした場合も自動で再適用される。項目はそれを追加したプラグインが読み込まれて初めて一覧に表示されるため、Vault を完全に開いてから並べ替えること。また、他のプラグインやコア設定・CSS スニペットで既に非表示にされている項目は検出できず一覧には出ない。
