## What's Changed

### New Features

- **プロパティリンク機能を追加**: フロントマターのlistプロパティ（例: `next`）に他ノートへのリンクを追加すると、リンク先ノートに対になるプロパティ（例: `previous`）を自動作成し、逆方向のリンクを追記するようになった。既存のプロパティや値は削除・上書きせず、追加のみを行う。`next`→`previous`のような有向ペアのほか、`friends`→`friends`のように同じ名前を指定すると対称な関係も作成できる。既定では無効で、設定の `Enable Property Link` から有効化し、Pair設定でプロパティ名の組を登録する。
- **手動同期コマンドを追加**: `Property link: Sync current note`（現在のノートのみ）と `Property link: Sync all notes`（Vault全体）で、自動検知を待たずに一括で対になるリンクを作成できる。
