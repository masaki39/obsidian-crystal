## What's Changed

### New Features

- **プロパティ名の色を個別に指定できる Property colors を追加**: Properties エディタのプロパティ名（キー）の文字色を、プロパティごとに指定できるようにした。**Settings → Property colors** の **Add rule** で行を追加し、プロパティ名と色を指定する。名前をカンマ区切りで並べると（例: `status, priority`）複数のプロパティに同じ色をまとめて指定でき、大文字・小文字は区別しない。表示上の色を変えるだけで、ノートの内容は変更しない。
- **全プロパティ共通の色を指定できる All properties**: 個別ルールのないすべてのプロパティ名に適用する色を指定できる。個別ルールが優先され、リセットボタンでテーマ本来の色に戻る。
- **カラーパレットから色を選択**: 各行にパレットのスウォッチを並べ、クリックで色を指定できる。パレットは **Color palette** で切り替えられ、既定は Tokyo Night（ほかに Catppuccin Mocha / Nord / Dracula / Gruvbox）。カラーピッカーで任意の色も指定できる。
- **プロパティ名の候補表示とプレビュー**: 名前の入力欄で Vault 内のプロパティ名を候補表示し、入力欄の文字をそのルールの色で表示する。新しいルールには、パレットのうちまだ使っていない色が自動で入る。
