## What's Changed

### New Features

- **Marp プレビューとエディタのカーソルを双方向に同期**: 設定の **Marp** セクションに 2 つのトグルを追加。**Move preview slide to cursor** をオンにすると、編集中のカーソル位置に合わせて Web Viewer で開いている Marp サーバーのプレビューが該当スライドへ移動する。**Move cursor to preview slide** はその逆で、プレビュー側でスライドを送るとエディタのカーソルがそのスライドの先頭へ移動する。Marp の bespoke テンプレートが持つハッシュ（`#<スライド番号>`）を書き換えて実現しているため、ページの再読み込みは発生しない。コアプラグイン **Web viewer** を使っている場合のみ動作し、外部ブラウザでは無効。スライドの区切り判定は Marpit の規則に合わせてあり、front matter・コードフェンス内の `---`・setext 見出しの下線は区切りとして数えない。
- **スライドの移動と並べ替えコマンドを追加**: `Marp: Go to next slide` / `Marp: Go to previous slide` で前後のスライド先頭へカーソルを移動、`Marp: Move slide down` / `Marp: Move slide up` でカーソル位置のスライドを前後のスライドと入れ替えられる。入れ替えは区切り記号の種類と位置、前後の空行をそのまま残して本文だけを交換するため、`---` と `***` が混在していても書式が崩れない。
- **スライド編集中にボタンを浮かせる機能を追加**: **Marp Slide Folder Path** 配下のファイルを編集モードで開いている間、エディタ右下に前後のスライドへの移動・スライドの並べ替え・PPTX/PDF エクスポート・Marp サーバーの起動/停止のボタンを表示する。サーバーボタンは起動状態に追従して表示が切り替わる。通常は半透明で、ホバーすると不透明になる。クリックしてもエディタのフォーカスは移らない。設定 **Show slide toolbar** でオフにできる。

### Changed

- **`Marp: Start server` がアクティブなスライドのページを直接開くように**: 実行時にアクティブファイルがスライドフォルダ配下の Markdown なら、トップページではなくそのファイルのページを開く。また、既に Marp サーバーを開いているタブがある場合は新しいタブを作らずそれを使い回す。

### Bug Fixes

- **Marp サーバーが気づかないうちに残り続ける問題を修正**: サーバーを独立したプロセスグループで起動してプロセスを保持するようにし、Obsidian の終了・プラグインの無効化・リロード時に確実に停止するようにした。以前は起動したサーバーが孤児プロセスとしてポート 8080 を握ったまま残り、その状態で再度起動すると新しいプロセスはポート衝突で即死するのに古いサーバーの応答で成功したように見えていた。起動前にポートの応答を確認して二重起動しないようにし、起動に失敗した場合は待機を打ち切って通知するようにしている。
- **`Marp: Stop server` が無関係なプロセスを終了させる問題を修正**: 以前はポート 8080 を使用しているプロセスを無条件に `kill -9` していたため、Web Viewer からの接続を保持している Obsidian 自身のネットワークプロセスや、別の開発サーバーを巻き込む可能性があった。このプラグインが起動したプロセスを直接停止し、それが無い場合のフォールバックでも marp のプロセスであることを確認してから終了するようにした。
