## What's Changed

### New Features

- **デイリーノートのインラインタイトルの後ろに曜日を表示**: デイリーノートを開くと、インラインタイトルの右側に曜日（例: `2026-09-21 Monday`、日本語環境では「月曜日」）を控えめに表示するようにした。ファイル名は変更せず CSS で表示するだけなので、タイトル編集にも影響しない。**Settings → Daily notes** の **Show weekday after inline title** で ON/OFF を、**Weekday format** で moment.js 形式の書式（`dddd` / `ddd` / `(ddd)` など）を切り替えられる。曜日の言語は Obsidian の表示言語に従う。
