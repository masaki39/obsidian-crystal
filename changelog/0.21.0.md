## What's Changed

### New Features

- **見た目を演出する Hacker mode を追加**: テーマの上に重ねる演出だけを追加するモード。**Hacker mode: Toggle** コマンドか **Settings → Hacker mode** でオン/オフし、各エフェクトを個別に切り替えられる。Obsidian 本体の DOM やノートの内容は変更しない。
  - **CRT overlay / Phosphor glow**: 走査線・ビネット・かすかなちらつきと、本文のほのかな発光、アクセント色のキャレット。
  - **Typing particles**: 打鍵ごとにキャレットから淡い 0/1 が漂い、連続入力でコンボを表示する。
  - **Boot sequence**: 起動時とモードをオンにしたときに、Vault の実データ入りの疑似ブートログを表示する（キーかクリックでスキップ）。
  - **Status bar HUD**: 時計・JS ヒープ使用量・タイピング速度（WPM）とスパークラインをステータスバーに表示する。
  - **Title decode**: ノートを開いたとき、タイトルがランダムな文字から確定していく（開いているタブへの切り替えでは出ない）。
  - **Reward banner**: Gamification の報酬に合わせて、レベルアップなどは中央に「ACCESS GRANTED」バナー、通常の XP は右上に 1 行を表示する。
  - **Background rain**: 画面全体にうっすら流れるデジタルレイン（既定はオフ、濃さを調整可能）。
- **下書きノートからデイリーノートへ投稿**: **Daily: Open draft** で下書きノート（既定は `tmp.md`）を開いて Markdown で書き、**Daily: Post draft to timeline** で今日のタイムラインに投稿時刻付きで追記する。投稿後は下書きが空になり（フロントマターは残る）、エディタで開いていれば Cmd+Z で戻せる。下書きの場所は **Settings → Daily notes → Draft note path** で変更できる。下書きノートは Auto link notes の対象外。
- **下書きノートから Bluesky へ投稿**: **Daily: Post draft to Bluesky** で下書きの本文を Bluesky に投稿する。下書き内の画像（`![](https://…)` / `![](相対パス)` / `![[画像]]`）は本文から外して最大 4 枚まで添付する。Bluesky の「デイリーノートに追記」がオンなら、画像入りの本文をタイムラインにも追記する。投稿に失敗した場合や、投稿中に下書きを編集した場合は下書きを消さない。
