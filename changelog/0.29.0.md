## What's Changed

### Bug Fixes

- **しばらく離れたあと Obsidian に戻るとフリーズする問題を改善**: ハッカーモードの **Background rain** を、Obsidian がバックグラウンドにある間（フォーカスが外れている・最小化中）は完全に止めてキャンバスを解放し、戻ってから少し遅れて再開するようにした。タイピングのパーティクル用キャンバスも、描くものが無い間は非表示にして全画面レイヤーを残さないようにした。

### New Features

- **ホームページを開くコマンド**: **Workspace: Open home page** を追加。**Settings → Crystal → General** の **Home page** に指定したノート（`Home` のようなノート名、または `Notes/Home.md` のようなパス）を現在のタブで開く。見つからない場合は通知する。Vim リーダーの既定キーは `Space h`。
- **リーダーマッピングの衝突チェック**: **Your mappings** に **Check for conflicts** を追加。自分のマッピング同士の衝突、デフォルトを置き換えるマッピング、未設定の行を一覧表示する。
- **コマンド選択で Ctrl+J / Ctrl+K**: リーダーマッピングのコマンド一覧で、Ctrl+J / Ctrl+K で選択を上下に動かせるようにした。

### Changed

- **キーヒントのコマンド名を短縮**: 狭いパネルに収まるよう、コマンド名からプラグイン名（`Crystal:` など）を省き、Crystal のコマンドはさらに機能名（`AI:` など）も省いて表示する。
- **キーヒントにハッカーモードの見た目を適用**: ハッカーモード中はパネルをターミナル風（アクセントカラーの枠と発光、等幅フォント）にした。
- **マッピング行の配置を変更**: **Your mappings** の各行を、左に `Space` ＋キー、右にコマンドと削除ボタンという一般的な配置にした。
- **内部の整理**: コマンド選択 UI を再利用できる独立クラスにしたほか、未使用コードや lint 指摘を整理した（動作は変わらない）。
