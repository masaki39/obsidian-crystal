## What's Changed

### Bug Fixes

- **ポップアウトから戻ったときに Background rain が止まったままになる問題を修正**: プラグインの再読み込み時にすでに開いていたポップアウトウィンドウも、フォーカスの監視対象にした。
- **衝突チェックの誤検出を修正**: 既定と同じキー・同じコマンドの行を「既定を置き換える」と表示しないようにした。

### Changed

- **コマンド名を「Crystal: 分類: 機能名」に統一**: キーヒントで分類名を省いても意味が通るよう、機能名だけで何をするか分かる名前に変更した（例: **Hacker mode: Toggle** → **Hacker mode: Toggle hacker mode**、**Focus: Left** → **Workspace: Focus left pane**、**Window: Toggle opacity** → **Workspace: Toggle window opacity**、**Quartz: Sync** → **Quartz: Sync Quartz**、**Marp: Start server** → **Marp: Start Marp server**）。コマンド ID は変わらないので、ホットキーやリーダーマッピングはそのまま使える。
