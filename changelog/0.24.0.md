## What's Changed

### Changed

- **UI・通知を英語に統一**: Notice、モーダル、ボタン、placeholder、設定画面に残っていた日本語をすべて英語にした。AI のプロンプト（description・git summary の出力言語など）は変更していない。
- **デフォルト値を見直し**: 新規ユーザーのノートが予告なく書き換えられないようにした。
  - **Auto Sort Tasks**・**Auto Link Notes** の既定を Off に変更。
  - **Draft note path** の既定を `tmp.md` から `Draft.md` に変更。
  - 設定を一度も変更していない（data.json に該当キーがない）環境では、上記の新しい既定値が適用される。以前の挙動を続けるには設定で有効化するか、Draft note path に `tmp.md` を指定する。
- **minAppVersion を 1.11.4 に引き上げ**: 使用している SecretStorage API に合わせた。

### Bug Fixes

- **Bluesky 投稿時の不要な Gyazo アップロードを修正**: **Post to Bluesky** でタイムライン追記がオフのとき、添付画像を Gyazo（公開）にアップロードしないようにした。
- **Quartz の未設定・失敗時の挙動を修正**: パスや GitHub ユーザー名が未設定なら中止して通知する。`npx quartz sync` が失敗したら終了コード付きでエラーを表示し、サイトを開かない。

### Removed

- **未使用の Publish Folder Path 設定を削除**: どこからも参照されていなかった。

### Documentation

- **README を全面刷新**: ロゴ・ヒーロー図・イラストを追加し、英語版（README.md）と日本語版（README.ja.md）を用意した。
- **機能別ドキュメントを追加**: `docs/en/`・`docs/ja/` に全機能・全コマンド・設定・外部通信（Network use & privacy）を整理した。
