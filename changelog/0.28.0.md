## What's Changed

### New Features

- **Vim モードの拡張（Vimrc Support の代替）**: Obsidian 標準の Vim モード向けに、**Settings → Crystal → Editor** の **Vim** に次の設定を追加した（j/k とクリップボード同期は既定でオフ）。ポップアウトウィンドウでも動作する。
  - **Move by display line**: Normal / Visual モードで `j`/`k` を `gj`/`gk` として動かす。
  - **Y yanks to end of line**（既定でオン）: Normal モードの `Y` を `y$` にし、`D`・`C` と同じく行末までを対象にする。
  - **Highlight yanked text**（既定でオン）: ヤンクした範囲を一瞬ハイライトする。
  - **Yank to system clipboard**: 無名レジスタへのヤンクをシステムクリップボードにもコピーする（`set clipboard=unnamed` 相当）。
- **Crystal のデフォルトのリーダーキーマップ**: Normal モードで Space に続けて 1〜2 キーを押すと、Crystal のコマンドを実行できるようにした（既定でオン）。最初のキーでグループ（`a` AI、`s` Bluesky 送信、`d` デイリー、`f` ファイル、`g` Gyazo、`e` 編集、`m` Marp、`p` Property link、`q` Quartz、`w` ウィンドウ）を選ぶ。よく使うグループはホームポジションに置き、`h`/`l` で前/次、`j`/`k` で下/上など Vim の感覚で押せる。`Space d d`/`d h`/`d l` は旧 vimrc と同じ。
- **自分のマッピングで上書き**: **Your mappings** で Space ＋キーに任意のコマンド（他のプラグインも可）を割り当てられる。同じキーや前方一致するキーのデフォルトを置き換え、**Do nothing** でキーやグループを無効にできる。
- **キーヒント（which-key 風）**: Space を押すと、次に押せるキーと動作を編集中のエディター下部に表示する。Esc で中止、Backspace で 1 キー戻る。表示までの遅延（既定 200 ms）は設定で変えられる。日本語 IME がオンでも物理キーで判定する。

### Changed

- **設定画面を Obsidian 推奨の形式に変更**: 各セクションを `SettingGroup` でまとめ、設定名を sentence case に揃えた（例: **Export Folder Path** → **Export folder**、**Auto Sort Tasks** → **Auto sort tasks**）。AI は OpenAI / Gemini / Ollama ごとのグループに分けた。検索結果にはセクション名を表示するようにした。保存されている設定値は変わらない。
