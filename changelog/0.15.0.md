## What's Changed

### New Features

- **AI プロバイダーに Ollama（ローカル稼働）を追加**: `AI Provider` で `Ollama (local)` を選ぶと、すべての AI コマンドがローカルの Ollama サーバー経由で動作し、ノートの内容は外部に一切送信されない。設定の `Ollama Base URL`（既定 `http://localhost:11434`）と `Ollama Model`（`ollama pull` 済みのモデル名、例: `llama3.1`）を指定して使う。Base URL 横の `Verify` ボタンでサーバーへの接続を確認できる。
