## What's Changed

### Changed

- **`Marp: Start server` がカーソル位置のスライドを開くように**: サーバー起動時に開くプレビューが、常に1枚目ではなく編集中のカーソルがあるスライドから表示されるようになった。アクティブなファイルがスライドフォルダ配下の Markdown で、そのファイルのエディタが開かれている場合に適用される。
- **`Marp: Stop server` がプレビューのタブも閉じるように**: サーバーを停止すると、Web Viewer で開いていた Marp サーバーのタブが閉じられるようになった（接続できないページが残らない）。外部ブラウザで開いた場合は従来どおり何もしない。
